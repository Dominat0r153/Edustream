# EduStream — Full-Stack Application

This package contains the integrated EduStream front end and Node.js/Express back end from Week 4, extended for Week 5 testing, debugging, and optimization.

## Week 5 additions
See `README_WEEK5.md` for the full Week 5 guide.

- Automated Jest + Supertest integration tests
- Front-end utility unit tests
- Validation and authentication regression tests
- Error log and debugging report
- Performance optimization report
- Repeatable benchmark script
- Windows test runner: `RUN_WEEK5_TESTS.bat`

## Application

From `backend/edustream-backend`:

```cmd
npm install
npm start
```

Open `http://localhost:5000`.

Or open `START_EDUSTREAM`
